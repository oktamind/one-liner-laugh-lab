One short funny line: the excuse a robot vacuum gives after eating a sock. Deadpan corporate twist — the sock was not eaten, it was promoted to lint.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
